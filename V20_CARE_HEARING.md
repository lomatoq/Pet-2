# Pet 2 v20 — забота, слух и быстрый полёт

Продолжает объединённую v19 без сброса памяти питомца.

- Правый клик по питомцу открывает компактное меню «Кормить / Научить».
- Кормление: клик выпускает три пульсирующие светящиеся крошки радиусом 2.4 px при эталонной высоте (до трёх активных). Питомец пробует перехватить их; оставшиеся падают с ускорением, мягко подпрыгивают и опускаются на верхнюю границу панели задач, проходя мимо окон. Поедание требует контакта текущей формы тела; всё лицо тянется к поверхности укуса, затем идёт короткая пауза. Насыщение и ограниченное положительное подкрепление начисляются после поедания. Esc или правый клик завершает режим; таймер — 90 секунд.
- Слух: индикатор микрофона, заметное внимание к тихим звукам и отскок от громкого резкого начала. Собственный голос не должен пугать питомца; между отскоками есть пауза.
- Обучение: выбрать имя или «тише», нажать Play, произнести пять отдельных примеров с паузами, затем пять других слов. Проверить новым произнесением. Акустическая модель локальная; сырые записи не сохраняются. Обучение своим голосом выполняет пользователь.
- Быстрый полёт: дополнительный запас скорости только для интенсивных движений. Сглаженное асимметричное поле меняет сами жидкие частицы: перед округлый, зад длиннее и уже. При замедлении поле возвращается к обычной форме. Контакт с опорой отключает форму кометы.

Это Windows-пакет. Pet2.exe и Pet2 Dev Console.exe должны оставаться рядом: второй файл содержит и компактное меню.

Дополнительные исправления по проверке пользователя:
- Вся геометрия лица смещается вместе; рот не отделяется от глаз.
- Ядро еды определяет физический радиус; свечение — только оптическое. Фаза свечения больше не теряет точность из-за огромных ID объектов.
- Объекты рисуются под телом, а не поверх лица.
- Команды захвата проверяют реальный контакт. Точка удержания берётся с текущей поверхности; пружина сохраняет инерцию и небольшое провисание.
- При холодном запуске восстанавливается собранная геометрия без старых скоростей. Индивидуальные свойства частиц, полная масса и память остаются.
- Меньшее гашение колебаний применяется только в движении; контроль растяжения и слияния сохраняется.

Проверка достижимости еды выявила фиксированный отступ навигации 176 px. Для пищевой цели используется измеренный контур тела, а обычные окна не отталкивают питомца от крошки на панели задач. Окончательное поедание проверяется отдельным нативным сценарием scripts/verify_v20_food.py.

Комбинируемые двигательные реакции: при интенсивном преследовании возможна короткая задержка торможения (до 110 мс, не чаще одного раза в 7 секунд). Реальный удар создаёт внутренний импульс сжатия без переноса центра массы. После контакта временно снижается напор; если цель остаётся недоступна, усилие вытягивания сочетается с боковым заходом по геометрии цели и курсора. Эти непрерывные реакции накладываются на текущие программы игры; это не случайное переключение заранее записанных трюков. Распознавание произвольных щелей между окнами пока не добавлено.
