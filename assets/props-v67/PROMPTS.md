# V67 moonlight prop family

Generated with the built-in image generation tool. Exact prompts are in
generation-prompts.json; source files are unchanged generated PNG bytes.

The user rejected the earlier realistic upholstered nest and requested one
coherent family for the home and capsule. These new generations use broad
moonlight-opal forms, a dark indigo recess and soft mint light. The ball uses
a different aurora-glass material with three large magnetic-looking lobes.

Runtime normalization adds/crops transparent canvas and builds alpha-correct
linear-light mipmaps. It does not recolor or paint over generated art.
Rejected source art is retained in the local report, outside the shipped set.
