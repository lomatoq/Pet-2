# Pet 2 organic embodied voice

Pet 2 has one production voice backend. A call is generated by breath pressure, a two-times-oversampled hybrid LF glottis, a moving oral/nasal Kelly–Lochbaum tract, and resonant modes driven by the current liquid body. There is no legacy oscillator, dry source bypass, sample pack, network model, or old/new runtime switch.

## Runtime module map

- `crates/lifecore/src/genome.rs`: stable, seeded `VoiceAnatomy` identity and legacy repair.
- `crates/lifecore/src/actions.rs`: learnable `VocalGesture`, canonical families, performance state, and `BodyVoiceFrame` contracts.
- `crates/pet_audio/src/breath.rs`: pressure build-up, airflow drain, capture threshold, fatigue, and release.
- `crates/pet_audio/src/glottis.rs`: hybrid LF flow derivative, two-times source oversampling, source–tract feedback, jitter, shimmer, and cycle changes.
- `crates/pet_audio/src/phonation.rs`: hysteretic stable, breathy, subharmonic, aperiodic, biphonic, and voice-break regimes.
- `crates/pet_audio/src/tract.rs`: 24-section-capacity oral tract, 6-section nasal branch, moving areas, constriction turbulence, and radiation.
- `crates/pet_audio/src/body_bridge.rs`: bounded lock-free latest-state transport and one-shot topology event analysis.
- `crates/pet_audio/src/body_resonance.rs`: six primary liquid modes and two detached-component satellite modes.
- `crates/pet_audio/src/motif.rs`: real-time scheduler, irregular closure-event purr, final DC/high-pass, saturation, 1.5–4% room, limiter, and pan.
- `crates/pet_audio/src/voice_diagnostics.rs`: callback-safe pressure, F0, cycle, tract, body, purr, finite-value, DC, and discontinuity counters.
- `app/src/main.rs`: derives body voice state from authoritative liquid diagnostics and publishes it to every audio restart.
- `tools/voice_lab`: deterministic 15-scenario WAV renderer and JSON quality manifest for the final backend.

## Fixed operating bounds

| Control | Bound |
| --- | --- |
| Audio control rate | 400 Hz |
| Glottal source oversampling | 2× |
| Active oral sections | 14–22 of 24 |
| Nasal sections | 6 |
| Body modes | 6 primary + up to 2 satellite |
| Voiced F0 | 85–1,600 Hz |
| Purr event rate | 22–31 Hz with irregular intervals; no final-bus AM |
| Voice high-pass | adaptive 42 or 58 Hz plus an 18 Hz DC blocker |
| Room wet mix | 1.5–4.0% |
| Limiter ceiling | 0.72–0.78 |
| Body bridge read | at most 4 seqlock attempts, then the previous valid frame |

The body affects tract length/compliance, modal frequencies and damping, body excitation, source back-pressure, and event transients. Stretch, compression, slosh, detachment, and remerge are therefore not implemented as pitch or gain presets.

## Voice Lab

Run:

```powershell
cargo run -p voice_lab --release -- --suite organic-embodied
```

Output is written to `artifacts/voice_lab/organic-embodied`. It contains 15 named WAV files and `manifest.json`. The manifest records the voice seed, full request, 100 Hz body timeline, pressure/F0/cycle/tract/body/purr diagnostics, signal gates, and final pass state.

## Verification

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo test --workspace
cargo run -p voice_lab --release -- --suite organic-embodied
cargo run -p pet2 --release -- --headless-smoke 30 --no-audio
cargo build --workspace --release
```

Physical-device listening remains a local release check because CI and headless runs do not own an output device. Offline rendering is sample-exact for the same voice, motif, request, and body timeline.
