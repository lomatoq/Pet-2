# Интеграция R12 в macOS

Дата: 2026-09-08.

Объединены `codex/pet2-macos-parity` (`11b30c0`) и
`codex/pet2-nervous-system-r12-impl` (`7687c4d`). Последний коммит target
подтверждён через GitHub HTTPS: SSH-доступ на машине отклоняется сервером.
Работа выполнена в текущей macOS-ветке; публикация на GitHub не выполнялась.

## Что перенесено

- R12: физическая обратная связь `BodyFeedbackV2`, интероцепция, эмоциональные
  состояния и ограниченное управление формой, материалом, движением и голосом.
- Распознавание телесных жестов, очередность взаимодействий, ограниченное
  обучение, сохранение материального состояния, защита топологии жидкости.
- Органический синтез голоса, связь с телом, исправления завершения звука;
  отдельный офлайн VoiceLab включён в macOS-пакет как инструмент.
- Поле притяжения логова, новая рябь, преломление фона, перенос предметов и
  исправления стабильности; корректное смешивание прозрачности для Metal.
- Новые калибровки Body, Den/Home, Voice/Sounds, Nervous/body встроены в
  Character существующей Dev Console. Живые нервные показатели и Accelerated
  Learning доступны в Diagnostics. Сохранены четыре основные панели F1–F4.
- Детерминированные программы обучения, pointer fixtures, конфигурации и
  диагностические отчёты исходной ветки.

## Что сохранено из macOS-ветки

- AppKit/Quartz, Retina, преобразования координат, клики по силуэту,
  системный Dock и работа overlay на пространствах macOS.
- Общая уменьшенная визуальная модель рабочего стола и анонимная карта
  восприятия в Dev Console.
- Поведение от потребностей, распознавание рабочего ритма, спокойное поведение
  при сосредоточенной работе пользователя и временные управляющие воздействия.
- Смягчённые halo/rim, миграция старых профилей свечения и authored black
  как базовая идентичность материала.
- Одна обычная, сворачиваемая Dev Console, прежние идентификаторы приложений,
  выбор Developer ID при упаковке, ZIP без дубликатов приложений в `dist`.

Готовые Windows EXE/ZIP из target и `RUN-DEN-LIVE.cmd` исключены из результата.
Исходники Windows сохранены; отдельное переименование консоли в PetLab и
возврат к двухрежимному окну F12 не перенесены.

## Найденные и исправленные проблемы

1. **На macOS отсутствовал фон для оптики R12.** Добавлен асинхронный Quartz
   capture окон ниже Pet, до 30 Гц, половина физического разрешения с
   пропорциональным ограничением 1920×1080. Очереди содержат максимум один
   запрос и один кадр. Координаты берутся из native frame в points, с
   преобразованием AppKit Y в Quartz Y. Отдельные тесты покрывают Retina и
   мониторы слева/сверху/снизу основного.
2. **Чистый macOS-фон мог замораживаться под логовом.** Новый контракт сообщает,
   что Pet исключён из каждого кадра на стороне платформы. Такие кадры обновляют
   фон целиком, без Windows-маски удержания старого изображения. Пиксели остаются
   только в памяти рендерера и не попадают в восприятие, логи или сохранения.
3. **Поиск исполняемого Pet не учитывал `.app`.** Dev Console сначала ищет
   соседний `Pet2.app/Contents/MacOS/Pet2`, затем development fallback.
   Добавлен тест приоритета установленного пакета над старой dev-сборкой.
4. **Windows/Linux утилиты в macOS-инструментах.** Отчёты открываются через
   `open`, SHA-256 вычисляется системным `/usr/bin/shasum -a 256`.
5. **Слабый порядок обмена телом и аудиопотоком на ARM.** Поля и счётчик кадра
   BodyVoiceBridge переведены в единый SeqCst-порядок. Читатель остаётся
   ограниченным четырьмя попытками, без блокировки аудиопотока. Добавлен
   конкурентный тест согласованности полей кадра.
6. **Светлая системная тема ломала контраст верхней панели.** Консоль явно
   фиксирует свою тёмную тему через ThemePreference, а не только initial visuals.
7. **Логово скрывалось за панелью настроек.** Все калибровочные разделы обновляют
   реальные границы preview; логово и orb привязаны к центру этой области.
8. **Тестовое нервное воздействие сохранялось при смене раздела.** Синтетическая
   actuation очищается при выходе из Nervous, включая режим паузы. LIVE логова
   по умолчанию выключен, сохраняя явное применение пользовательских изменений.
9. **CI проверял старую структуру пакета.** Проверка извлекает ZIP во временную
   папку, проверяет Dev Console, оба инструмента и подписи приложений.
10. Исправлены предупреждения строгого Clippy в новых R12-модулях; локальные
    исключения оставлены только у функций с явно связанными группами параметров.

## Ограничения результата

- Полный живой desktop-overlay, его новый Quartz-фон с выданным разрешением
  Screen Recording и реальные переходы между разношкальными мониторами не
  подтверждены этой сессией. Проверен Metal preview консоли; это не равнозначно
  полной проверке преломления поверх рабочего стола.
- Три длительных production replay и fixture-regeneration test остаются
  явно ignored; Windows-сборка и runtime на этой машине не запускались.
- Унаследованные офлайн curriculum/pointer replay используют R11 interaction
  loop, без полного live R12 interoception/phenotype loop. Их результаты
  проверяют обучение и инварианты этого режима, а не визуальную эквивалентность
  живому R12. Это ограничение теперь явно указано в UI и документации.
- На машине нет выбранной Developer ID identity: пакет имеет ad-hoc подпись,
  поэтому непрерывность TCC-разрешений между изменёнными бинарниками не
  гарантируется. Механизм подписи Developer ID в macOS-ветке сохранён.
- Зависимость `block 0.1.6` выдаёт уведомление future-incompatibility Rust;
  текущие сборка, тесты и строгий Clippy проходят.
