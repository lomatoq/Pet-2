## Variation contract

Variation is sampled at the start of a causal performance, never every frame.
Small changes in tempo, amplitude, asymmetry, preparation/recovery proportions,
stroke shape and safe object impulses distinguish repetitions. Fatigue/load
constrain variation. Learned gesture pace applies to the matching gesture bout.
Human response waits, protective blink ownership, contact constraints and safety
priorities are not randomized. A fixed seed and event sequence replay exactly.

Game and placement adaptation is bounded **within-session memory**. Successful
physical outcomes strengthen it; confirmed failures or explicit refusal weaken
it. Silence is not treated as negative learning evidence. Current source does
not claim persistence of these new preferences between application launches.

The first 90-second headless acceptance run failed real orb movement. Investigation
found inconsistent fixture assumptions: continuous typing at midnight, old fixed
center limits, and missing native presentation/motion-space setup. These are not
accepted as a passing behavior test. A corrected representative fixture must still
pass the original contact and orb-distance requirements before delivery.

The corrected fixture then exposed a production defect: real ApplyImpulse
commands released the stored orb, but den attraction immediately recaptured it
in the same physics step. The existing release-grace interval now also blocks den
recapture, not just body separation. Normal capture resumes after that interval;
explicit storage and gentle handoff retain their existing paths.

These are source and deterministic-test findings. They do not establish that all
behaviors look natural in long-term use. Numerical contact uses a bounded sweep
(32 intervals), not mathematically exact continuous collision detection.
